## Poetry
Poetry is a Python dependency and project manager.

Why use Poetry:
- Keeps project dependencies isolated and reproducible.
- Uses `pyproject.toml` as a single source of truth.
- Generates `poetry.lock` so everyone installs exact versions.

## Quick start
```bash
poetry install
poetry run python main.py
```
