# LLMs

This folder groups application-driven LLM projects, each built around a practical use case such as code generation, document analysis, or customer support.

## What This Area Covers

- Task-specific LLM workflows (QA, summarization, generation, analysis).
- Notebook-first experimentation with pretrained models.
- Prompting and inference pipelines for real-world scenarios.

## Core Concepts Implemented

- Instruction prompting for domain tasks.
- Summarization and long-text handling.
- QA/chatbot response generation.
- Model selection by task type.

## Projects In This Folder

- `Code Generator/(codegen)Code_Generation_with_LLM.ipynb`
  - Code generation pipeline.
- `Customer Service Chatbot/LLM_based_Customer_Services_Chatbot.ipynb`
  - Customer support QA chatbot.
- `Excel Data Analyzer/(Gemini)_Excel_Data_Analyzer.ipynb`
  - Spreadsheet question-answering/analysis.
- `Legal-Document-Analyzer/LLM_based_Summerizer_Chatbot.ipynb`
  - Legal summarization chatbot.
- `Legal-Document-Analyzer/Legal_Document_Analyzer.ipynb`
  - Legal document analysis + summarization experiments.
- `Short Story Generator/Short_Story_Generator.ipynb`
  - Creative story generation.
