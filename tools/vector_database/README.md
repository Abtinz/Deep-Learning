# vector_database

This folder contains vector database learning material, focused on ChromaDB workflows.

## What Vector Databases Mean Here

- A vector database stores embedding vectors for semantic retrieval tasks.
- Instead of SQL-style exact matches, retrieval is based on distance/similarity in embedding space.
- This is a core building block for RAG and semantic search systems.

## Core Concepts Implemented

- Chroma client and collection management.
- Adding text/documents and storing embeddings.
- Similarity-based querying.
- Understanding distance metrics (for example cosine similarity concepts in notebook explanation).
